# Web Page Design

A responsive web page built with HTML and CSS. The project demonstrates a clean layout, thoughtful typography, and a consistent visual style across desktop, tablet, and mobile screens.

## Features

- Responsive layout for different screen sizes
- Semantic HTML structure
- Consistent typography, colors, and spacing
- CSS styling organized for easy updates
- Simple navigation and clear content hierarchy

## Technologies

- HTML5
- CSS3

## Getting Started

1. Clone this repository.
2. Open `index.html` in a web browser.

## Customization

Update the HTML to change the page content. Edit the CSS styles to adjust colors, typography, spacing, and layout.
